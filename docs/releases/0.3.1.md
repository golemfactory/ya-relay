# ya-relay-server 0.3.1

This release rebuilds the relay server through a CI pipeline with fresh Cargo,
Rust toolchain and build directories. It does not restore Actions caches.

The release includes the session lifecycle, reconnect and handshake admission
changes already on `main`. The source snapshot also contains the virtual TCP
source-address check and randomized smoltcp interface seed; those two changes
affect clients, rather than adding server functionality.

Release dependencies are recorded in the committed `Cargo.lock`. Two separate
GitHub-hosted jobs build the Linux x86-64 glibc binary and Debian package in
Debian 13 (trixie), using an image pinned by digest. Publication
requires byte-identical binaries and packages, matching checksums and a build
provenance attestation. Compilation has read-only repository permissions;
attestation and publication run in separate jobs without executing project code.

Assets include the server binary, Debian package, lockfile, `BUILD-INFO.json` and
`SHA256SUMS`. The Debian package installs `/usr/bin/ya-relay-server`; it does not
create or start a system service. Its runtime dependencies are generated from the
binary using `dpkg-shlibdeps`. CI installs and runs the package in a separate
Debian 13 container. Production binaries explicitly enable `ui,metrics`.
CI checks `/ui/`, `/status`, `/metrics` and the `/events` SSE endpoint in the
installed package. Embedded UI assets are ordered deterministically during the
build. Compatibility with older Debian releases is not part of this validation.

HTTP listens on `127.0.0.1:9000` by default. Override the address with
`--metrics-scrape-addr`. For example, read live node events with:

```sh
curl -N http://127.0.0.1:9000/events
```

The events are `new-node`, `lost-node` and `drop` (subscriber lag). The stream
contains new events rather than historical replay.

Before running an asset, verify its checksum and provenance:

```sh
sha256sum --check SHA256SUMS
gh attestation verify ya-relay-server --repo golemfactory/ya-relay --signer-workflow golemfactory/ya-relay/.github/workflows/release.yml --source-ref refs/tags/v0.3.1
```

Checksums detect differences from the supplied manifest. Provenance must also
match the expected release tag and source commit. Neither passing tests nor
matching independent builds proves that source code has no vulnerabilities.
